# Panduan Pengambilan Screenshot Referensi (Assets)

Agar otomatisasi berjalan akurat, simpan screenshot kecil (crop/potong bagian pentingnya saja, jangan seluruh layar) ke dalam folder ini dalam format `.png`.

Gunakan tombol keyboard bawaan Windows: **`Windows + Shift + S`** untuk memotong gambar dengan rapi.

---

### Daftar File yang Diperlukan:

1. **`btn_login.png`**
   * Potongan tombol "Log On" atau "Masuk" pada halaman web Citrix StoreWeb.
2. **`icon_ax.png`**
   * Potongan ikon atau teks "Dynamics AX" pada daftar aplikasi di web Citrix StoreWeb.
3. **`menu_stock.png`**
   * Potongan teks menu *Available stock position & item price* di dalam Axapta.
4. **`window_stock.png`**
   * Potongan judul / header jendela data stok yang baru terbuka (sebagai penanda bahwa jendela sudah selesai loading).
5. **`btn_export.png`**
   * Potongan tombol "Export" (atau ikon Excel/Export) di jendela data Axapta.
6. **`btn_save.png`** *(Opsional)*
   * Potongan tombol "Save" pada dialog penyimpanan file Windows.

---

### Tips Penting:
* **Gunakan ukuran secukupnya:** Jangan screenshot 1 layar penuh, cukup potong area tombol/ikonnya saja (misal ukuran 60x30 pixel atau seukuran tombol).
* **Pastikan Display Scaling konsisten:** Jika laptop menggunakan display scale 125% atau 100%, jangan ubah resolusi/scaling layar setelah gambar disimpan.
